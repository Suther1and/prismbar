# TestBar — Product Requirements Document

## 1. Обзор и цели
**TestBar** — настольное приложение для Windows 11 (`.exe`), заменяющее штатную нижнюю панель задач и меню «Пуск». Приоритет продукта: премиальный современный визуал, естественные плавные анимации, мгновенный отклик и надёжная работа каждый день без поломки системной оболочки Windows.

## 2. Целевые сценарии (User Journeys)

### UJ-1: Ежедневный запуск и переключение окон (Артём, работает с 6–8 окнами на 2К-мониторе)
1. Артём включает ПК — TestBar стартует автоматически, штатная панель Windows 11 мягко скрывается, рабочая область экрана корректно подстраивается.
2. На нижней панели видны закреплённые приложения и текущие запущенные окна с чётким индикатором активного окна.
3. При наведении на иконку браузера с 2 окнами плавно всплывает карточка-превью окон с возможностью кликнуть нужное или закрыть его крестиком.
4. Клик по активному приложению сворачивает его, по неактивному — мгновенно выводит на передний план.

### UJ-2: Мгновенный запуск через «Пуск» (Артём ищет приложение или настройку)
1. Артём нажимает клавишу `Win` (или кликает кнопку «Пуск»).
2. За < 50 мс с упругой анимацией появляется компактное стеклянное меню «Пуск» прямо над панелью, фокус уже стоит в строке поиска.
3. Артём вводит «tel» — мгновенно фильтруется Telegram, нажатие `Enter` запускает его и закрывает меню.
4. Если Артём нажимает `Win+E` или `Win+Shift+S`, системный шорткат Windows срабатывает штатно, «Пуск» TestBar не мешает.

### UJ-3: Быстрое управление системой без ухода в Параметры Windows
1. Артём наводит на блок громкости/сети справа, прокруткой колёсика мыши над ним меняет громкость на лету (или кликает, открывая Центр управления).
2. В Центре управления одним кликом переключает Wi-Fi / Bluetooth / Ночной свет / Не беспокоить, двигает ползунок громкости или выбирает устройство вывода звука.
3. Рядом видит текущий трек из Spotify/браузера в компактном мини-плеере (пауза/следующий) и текущую раскладку (`RU`/`EN`).
4. Клик по часам открывает аккуратный календарь с быстрым обзором месяца.

### UJ-4: Кастомизация и безопасный откат
1. Правый клик по панели → «Настройки TestBar». Артём переключает компоновку с «Парящего дока» на «Раздельные острова» или «Классическую полосу», меняет акцент и тему — всё применяется мгновенно с плавным морфингом.
2. Если Артём запускает игру в полноэкранном режиме, панель автоматически скрывается и не мешает.
3. При выходе из TestBar или нажатии аварийной комбинации `Ctrl+Alt+Shift+Esc` штатная панель Windows 11 мгновенно возвращается на место.

## 3. Функциональные требования (FR)

### Группа A: Панель задач и управление окнами
- **FR-01 (Интеграция рабочей области):** Резервирование нижней полосы экрана (AppBar) так, чтобы развёрнутые окна не уходили под панель, с пересчётом при смене разрешения, DPI и мониторов.
- **FR-02 (Безопасная подмена штатной панели):** Опция скрытия штатной `Shell_TrayWnd` (и `Shell_SecondaryTrayWnd`) при активном TestBar с гарантированным восстановлением при выходе, краше (watchdog) или по хоткею `Ctrl+Alt+Shift+Esc`.
- **FR-03 (Закреплённые и запущенные приложения):** Отображение списка закреплённых приложений и всех видимых пользовательских окон Windows (с нативными иконками высокого разрешения, группировкой по приложению и поддержкой Drag-and-Drop переупорядочивания закреплённых).
- **FR-04 (Индикация состояний окон):** Визуальное различие состояний: не запущено, запущено в фоне, активно в фокусе, свернуто, требует внимания (мигание окна), несколько окон одного приложения.
- **FR-05 (Действия с окнами):** Клик — фокус/сворачивание; средний клик — запуск нового экземпляра; правый клик — контекстное меню (Закрепить/Открепить, Новое окно, Закрыть окно / Закрыть все).
- **FR-06 (Превью окон при наведении):** При наведении на запущенное приложение всплывает компактная карточка с заголовками окон, миниатюрой/иконкой и кнопкой закрытия.
- **FR-07 (Режим полноэкранных приложений):** Автоматическое скрытие панели при активном полноэкранном окне (игры, видео) и плавное возвращение при выходе из него.

### Группа B: Меню «Пуск»
- **FR-08 (Триггеры открытия):** Открытие по клику на кнопку «Пуск» и по одиночному нажатию клавиши `Win` без поломки системных комбинаций `Win+<клавиша>`. Закрытие по `Esc`, повторному `Win` или клику вне меню.
- **FR-09 (Мгновенный поиск):** Поле поиска с автофокусом и моментальной фильтрацией установленных приложений (Start Menu `.lnk`, UWP/Store apps, системные утилиты), навигацией стрелками и запуском по `Enter`.
- **FR-10 (Закреплённые приложения):** Настраиваемая сетка закреплённых приложений в «Пуске» с возможностью закреплять/откреплять и менять порядок.
- **FR-11 (Все приложения):** Переключение на алфавитный прокручиваемый список всех установленных программ Windows.
- **FR-12 (Недавние и быстрые папки):** Компактный блок недавних файлов/папок + кнопки быстрого перехода (Проводник/Документы/Загрузки/Параметры Windows).
- **FR-13 (Меню питания):** Всплывающее меню в нижней части «Пуска»: Блокировка, Сон, Перезагрузка, Выключение (с защитой от случайного клика для перезагрузки/выключения).

### Группа C: Системный трей, Центр управления и виджеты
- **FR-14 (Системные часы и календарь):** Отображение текущего времени и даты; по клику — всплывающий интерактивный календарь на месяц с переключением месяцев и быстрым возвратом на «Сегодня».
- **FR-15 (Индикатор раскладки клавиатуры):** Отображение актуального языка ввода (`RU`, `EN` и др.) активного окна в реальном времени и переключение раскладки по клику.
- **FR-16 (Центр управления — Quick Settings):** Единая кнопка (сеть + звук + батарея) открывает всплывающую панель:
  - регулировка громкости (ползунок + mute + прокрутка колёсиком мыши прямо на иконке панели),
  - выбор устройства вывода звука,
  - статус и быстрое переключение Wi-Fi / Bluetooth / Ночной свет / Не беспокоить (либо открытие системного диалога там, где Windows ограничивает прямой переключатель),
  - статус батареи (на ноутбуках) и яркость экрана (DDC/WMI при поддержке).
- **FR-17 (Мини-плеер SMTC):** Автоматическое отображение текущего играющего медиа из Windows Media Session (Spotify, браузер, плееры): название трека, кнопка Play/Pause, Next/Prev, скрывается когда ничего не играет (опционально в настройках).
- **FR-18 (Трей фоновых приложений):** Отображение сворачиваемой области фоновых значков (или быстрый доступ к системному overflow) + собственный значок TestBar с быстрым меню выхода и восстановления штатной панели.
- **FR-19 (Опциональный мини-виджет слева):** Компактный настраиваемый модуль: CPU/RAM мониторинг и/или погода (включается/выключается в настройках, чтобы не перегружать панель тем, кто любит абсолютный минимализм).

### Группа D: Персонализация, настройки и надёжность
- **FR-20 (Режимы компоновки панели):** Переключение на лету между 3 режимами:
  1. **Floating Dock** (парящий док с отступом снизу и скруглением),
  2. **Edge-to-Edge Bar** (цельная полоса на всю ширину экрана),
  3. **Split Islands** (три раздельных парящих острова: левый виджет, центр с Пуском и окнами, правый системный блок).
- **FR-21 (Темы и материалы):** Режимы темы: Тёмная (*Obsidian Glass*), Светлая (*Frosted Pearl*), Авто (синхронизация с Windows 11). Настройка степени прозрачности/размытия и выбор акцентного цвета (или синхронизация с акцентом Windows).
- **FR-22 (Размеры и поведение):** Выбор размера панели (Компактная / Стандартная / Комфортная), включение/выключение автоскрытия, настройка видимости отдельных модулей (медиа, CPU/RAM, погода, раскладка).
- **FR-23 (Автозапуск и хранение настроек):** Автозапуск вместе с Windows (через реестр `HKCU\...\Run`), сохранение конфигурации и списка закреплённых приложений в локальный JSON (`%APPDATA%\TestBar\config.json`).
- **FR-24 (Мультимониторность — базовая в v1.0):** Работа на основном мониторе по умолчанию + опция выбора монитора (полная независимая панель на каждом мониторе — как расширение v1.0/v1.1).

## 4. Нефункциональные требования (NFR)
- **NFR-01 (Плавность):** Анимации интерфейса строго на GPU-композиторе (`transform`, `opacity`, аппаратный blur), 60–240 FPS в частоте монитора, без подёргиваний при открытии «Пуска» и наведении на иконки.
- **NFR-02 (Отклик):** Открытие меню «Пуск» ≤ 50 мс, фильтрация поиска ≤ 15 мс, клик по окну на панели ≤ 20 мс.
- **NFR-03 (Потребление ресурсов):** В простое CPU < 1%, RAM ≤ 120 МБ (при активном UI), отсутствие утечек памяти при суточной работе.
- **NFR-04 (Железная стабильность):** Никаких патчей/инъекций в системные DLL и `explorer.exe`. Автоматическое восстановление штатной панели через сторожевой механизм при аварийном завершении. Реакция на перезапуск `explorer.exe` (`TaskbarCreated`).
- **NFR-05 (Автономность сборки):** Собранный `.exe` работает на чистой Windows 11 (используя встроенный в ОС WebView2 Runtime) без установки сторонних рантаймов.
- **NFR-06 (Доступность и эргономика):** Чёткий контраст текста ≥ 4.5:1 на обеих темах, полная клавиатурная навигация в «Пуске», поддержка настройки «Уменьшить движение» (`prefers-reduced-motion`).

## 5. Открытые вопросы (подтвердить на UX-ревью)
1. **Дефолтный стиль панели:** Какой из 3 режимов сделать главным по умолчанию — *Floating Dock*, *Split Islands* или *Edge-to-Edge Bar*?
2. **Название продукта:** Оставляем рабочее название **TestBar** или меняем на более продуктовое (например, *AuraBar*, *LumaBar*, *VeloBar* или свой вариант)?
3. **Левый виджет по умолчанию:** Показывать ли по умолчанию компактный CPU/RAM / погоду слева или держать панель максимально чистой (только центр и правый блок, а виджет включать в настройках)?
4. **Мини-плеер на панели:** Показывать прямо на панели (когда играет музыка) или спрятать внутрь Центра управления?
5. **Поддержка нескольких мониторов:** Нужна ли в v1.0 панель на всех мониторах сразу или достаточно основного монитора?
