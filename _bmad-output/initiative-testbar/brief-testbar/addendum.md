# Product Brief — Addendum (Исследование рынка и технических ограничений Windows 11)

## Конкурентный ориентир
- **Seelen UI (Open Source, Tauri/WebView):** сильная эстетика (парящий док, динамические акценты, модули), работает как оверлей без патча `explorer.exe`. Минусы: перегружен тайлингом и настройками, бывает тяжёлым и не всегда аккуратно дружит с XAML-островами Win11.
- **Windhawk:** лёгкий, но требует инъекции кода в `explorer.exe`, что ломается после крупных апдейтов Windows 11.
- **StartAllBack:** сверхстабильный, но платный, закрытый и ориентирован на ретро-стиль Win10/Win7, а не на современный дорогой минимализм.

## Вывод по нише TestBar
Ниша свободна для **чистого, визуально безупречного, сфокусированного только на панели задач и «Пуске»** продукта без комбайна из тайлинга и без рискованных DLL-инъекций в `explorer.exe`.

## Критические технические риски Windows 11 (учесть в PRD и Архитектуре)
1. **Скрытие `Shell_TrayWnd` и `Shell_SecondaryTrayWnd`:** нельзя убивать `explorer.exe` — нужно мягко скрывать (или переводить в auto-hide / уводить за край) с немедленным восстановлением при штатном выходе и через отдельный лёгкий watchdog/обработчик краша.
2. **Резервирование экрана (`SHAppBarMessage` + `SPI_SETWORKAREA`):** необходимо обрабатывать событие `TaskbarCreated` (перезапуск `explorer.exe`), смену DPI (`WM_DPICHANGED`) и подключение/отключение мониторов.
3. **Полноэкранный режим (игры, видео на весь экран):** панель должна автоматически уходить с переднего плана при обнаружении fullscreen-окна (`SHQueryUserNotificationState` / сравнение `GetWindowRect` с `MONITORINFO`).
4. **Перехват клавиши `Win`:** низкоуровневый хук `WH_KEYBOARD_LL`, который открывает наш «Пуск» только по одиночному нажатию и отпусканию `LWin`/`RWin`, НЕ ломая системные комбинации (`Win+E`, `Win+D`, `Win+R`, `Win+L`, `Win+Shift+S`, `Win+V`, `Win+Tab`).
5. **Окна панели:** стиль `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE` для самой панели, чтобы клик по панели не воровал фокус у активного окна до момента переключения, и сама панель не попадала в `Alt+Tab` и в свой же список окон.
